C does not follow the BODMAS rule (Brackets, Orders, Division, Multiplication, Addition, Subtraction) in evaluating expressions.

The order of precedence of expressions in C:
Parentheses: (),
Unary Operators: ++, --, -(negative), !(not),
Multiplicative: *, /, %
Additive: +, -
Relational / 
Logical: <, >, ==, &&, ||
Assignment: =

UPC: Universal Product Code - Bar code
